# Melt the World's Biggest Ice Block (Roblox)

Melt enormous ice blocks with increasingly powerful heaters, find the frozen treasures inside, and reach the centre.

- **Design, balance and code map:** [`GAME.md`](GAME.md)
- **Skill guides used for this project:** [`docs/skills/`](docs/skills/). These cover Roblox game dev, stud-style building, UI, VFX, score and trailers. Read them before making changes.

## Run in Roblox Studio
1. Install [Rojo](https://rojo.space), then run `rojo serve` in this folder.
2. In Studio, connect with the Rojo plugin and press Play.

## Browser prototype
`web/index.html` is a browser version of the same loop, using the same numbers. For the Alloy preview, it is served by `docker-compose.alloy.yaml` on port 3000.
